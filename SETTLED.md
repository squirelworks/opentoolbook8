# Settled

A reader behavior is implemented only after it is written here. One behavior per change. A page, a script, a paint rule, or a lesson zip that is not written here is not implemented.

## Missing files are reported, not fatal

Logic Families (`9e954d01.tbk`) names `minstb32.dll`. That file is not shipped. Opening the book reports it and still returns the book. Any other file the book names and the folders do not hold is reported the same way. The open does not stop.
